# mps-team-cn/.github

这是 `mps-team-cn` 的组织级配置仓库，用于集中维护 GitHub 组织主页、Issue / Pull Request 模板，以及基础协作说明。

## 仓库用途

本仓库主要用于提供以下内容：

- GitHub 组织主页文件
- 组织级 Issue 模板与 PR 模板
- 基础贡献说明与安全说明
- 面向多个仓库共享的协作入口与提交规范

如果某个子仓库没有单独覆盖对应配置，GitHub 会优先使用这里的组织级默认配置。

## 当前包含

- `https://mpsteam.cn/`：组织主站与对外窗口
- `profile/README.md`：GitHub 组织主页
- `.github/ISSUE_TEMPLATE/`：组织级 Issue 模板
- `.github/PULL_REQUEST_TEMPLATE.md`：组织级 PR 模板
- `CONTRIBUTING.md`：基础贡献说明
- `SECURITY.md`：安全说明

## 适用范围

本组织围绕 Multiple Personality System / 多意识体系统相关项目开展开源协作，包括知识库、网站、工具脚本与维护性配置。

内容整理与协作目标以中立、客观、可靠为主，不提供医疗、心理咨询、诊断或危机干预服务。

**免责声明：项目内容仅供知识整理与参考，不构成医疗建议；如涉及诊断、治疗或危机情况，应寻求持证专业人员或当地紧急服务支持。**
