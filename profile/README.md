# mps-team-cn

`mps-team-cn` 是一个围绕 Multiple Personality System / 多意识体系统主题展开的开源协作组织，用于维护相关项目、知识库、网站与工具。

我们当前主要关注：

- 多意识体系统相关中文资料的整理、索引与持续修订
- Wiki、词条、主题导览与术语体系建设
- 网站前端、内容发布、工具脚本与自动化维护
- 为内容修订、翻译校对、问题反馈与工具开发提供协作入口

我们的目标不是提供商业化服务，也不是将复杂议题简化为宣传材料，而是尽量以中立、客观、可靠的方式，建设可持续维护的中文资料与开源基础设施。

## 组织简介

本组织承载与多意识体系统相关的知识整理、站点建设和配套工具开发。内容覆盖概念框架、术语说明、系统运作、临床相邻主题、创伤与基础安全资源等方向。

我们尽量保持以下原则：

- 以公开可核对的信息整理为基础
- 区分知识说明、经验材料与临床主题
- 避免夸大、神化、标签化或过度承诺
- 在敏感议题上优先强调安全、边界与可验证性

## 主要项目

- [Multiple_personality_system_wiki](https://github.com/mps-team-cn/Multiple_personality_system_wiki)：多意识体系统主题开放式知识库
- [Multiple_personality_system_home](https://github.com/mps-team-cn/Multiple_personality_system_home)：主站与组织对外页面相关代码
- [mps-wiki-starlight](https://github.com/mps-team-cn/mps-wiki-starlight)：Wiki 站点前端与实现相关仓库
- [主 Wiki](https://wiki.mpsteam.cn/)：公开访问的多意识体系统中文百科与主题导览

## 如何参与

欢迎以下类型的贡献：

- 修正文案错误、失效链接、格式问题与结构问题
- 补充词条内容、参考资料、术语说明与交叉链接
- 进行翻译、校对与中文表述统一
- 反馈网站显示错误、功能异常与工具脚本问题
- 提出页面体验优化、工具需求与自动化改进建议

如果你准备参与：

1. 先阅读对应仓库的 `README`、`CONTRIBUTING.md` 与模板说明。
2. 内容问题优先使用 Issue 反馈，较小改动可直接提交 Pull Request。
3. 涉及敏感主题时，请尽量使用中性表述，并避免公开暴露个人隐私与高风险细节。

## 安全与边界

本组织是知识整理与开源协作项目，不提供医疗、心理咨询、危机干预或个体化诊断服务。

**免责声明：项目内容仅供知识整理与参考，不构成医疗建议；如涉及诊断、治疗或危机情况，应寻求持证专业人员或当地紧急服务支持。**

请特别注意：

- 不要将仓库内容视为诊断依据、治疗方案或紧急处置指令
- 不要在公开 Issue 或 PR 中提交隐私信息、病历资料、联系方式、密钥或令牌
- 若内容涉及自伤、他伤、急性危机或明显失控风险，请优先联系当地紧急服务或线下持证专业人员

## 反馈渠道

- GitHub Issues：用于错误反馈、功能建议、内容修订与工具问题
- Pull Requests：用于直接提交内容修订、文案优化与代码改进
- 信息反馈邮箱：`support@mpsteam.cn`
- 官方联系邮箱：`contact@mpsteam.cn`

如果反馈内容包含安全问题、隐私泄露、账号风险或不适合公开讨论的信息，请不要直接发布公开 Issue，优先参考 [SECURITY.md](https://github.com/mps-team-cn/.github/blob/main/SECURITY.md) 中的说明。
