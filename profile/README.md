# MPS Team CN

**理解多意识体，从科学与同理出发。**

**MPS Team CN** 是一个围绕 **Multiple Personality System / 多意识体系统** 建立的中文资料与开源协作组织。

我们主要维护多意识体相关的科普内容、Wiki 词条、主题导览、术语说明，并负责网站前端与配套工具。我们希望能为关注这个主题的人，提供一个稳定可靠、方便查阅、持续更新的中文入口。

## 我们在做什么

- 整理多意识体系统相关的中文资料
- 维护 Wiki、词条、主题导览与术语体系
- 优化网站前端、内容发布流程与自动化工具
- 处理内容修订、翻译校对、问题反馈与协作贡献
- 收集与维护基础安全资源、危机支持资源及相关说明

## 主要项目

- [mpsteam.cn](https://mpsteam.cn/)：组织主站与信息入口
- [主 Wiki](https://wiki.mpsteam.cn/)：多意识体系统中文百科与主题导览
- [Multiple_personality_system_wiki](https://github.com/mps-team-cn/Multiple_personality_system_wiki)：Wiki 内容仓库
- [Multiple_personality_system_home](https://github.com/mps-team-cn/Multiple_personality_system_home)：主站相关代码
- [mps-wiki-starlight](https://github.com/mps-team-cn/mps-wiki-starlight)：Wiki 站点前端与实现仓库

## 欢迎参与

你可以通过 Issue 或 Pull Request 参与以下工作：

- 修正文案、错别字、失效链接与格式问题
- 补充词条内容、参考资料与交叉链接
- 参与翻译、校对和中文表述的统一
- 反馈网站显示错误、功能异常或工具问题
- 提出页面体验、内容结构或自动化流程的改进建议

开始前，建议先阅读对应仓库的 `README`、`CONTRIBUTING.md` 以及 Issue / PR 模板。

## 我们的宣言

MPS Team CN 不是唯一的答案，也不试图成为唯一的入口。

我们只是希望，在中文世界里，为多意识体相关的资料整理、公共讨论和安全支持，留下一处可以被看见、被修订、被继续建设的地方。

> 如果有一天，你也在别处点起了新的火种，请记得：光不属于任何人，但每一个守火者，都会彼此看见。

## 安全与边界

MPS Team CN 是一个知识整理与开源协作项目，不提供医疗、心理咨询、危机干预或个体化诊断服务。

项目内容仅供知识整理与参考，不构成医疗建议。在涉及诊断、治疗、急性危机、自伤或他伤风险时，请优先寻求持证专业人员、当地紧急服务或线下支持资源。

请不要在公开 Issue、Pull Request 或讨论区内提交隐私信息、病历资料、个人联系方式、账号密码、密钥或任何令牌。
